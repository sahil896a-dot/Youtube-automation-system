# YouTube Automation System (Beginner-Friendly)

This simple Python project helps you create a short YouTube script automatically.

## What it does
- Picks a **trending-style history topic** for a **USA audience**.
- Generates a **60-second script** with:
  - Hook
  - Storytelling
  - Climax
- Saves the output into `generated_youtube_script.txt`.

## Run it
```bash
python3 youtube_automation.py
```

After running, open:
- `generated_youtube_script.txt`
